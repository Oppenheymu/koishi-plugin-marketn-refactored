# P5–P6 计划：宿主联调验收与收尾

> 状态：**待执行**（P4 已完成，P5 进行中）。宿主集成机制考据：[reference/构建与宿主接线.md](reference/构建与宿主接线.md)。开发依据见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## P5 宿主联调

### 1. 前置：环境切换

1. 宿主 root `yarn install`（确保新 devDeps 就位）。
2. `yarn workspace koishi-plugin-marketn-refactored build`——**必须先产出 lib/ 与 dist/**（宿主 loader 无 `--conditions development`，永远解析 `lib/node/index.cjs`，未构建直接 MODULE_NOT_FOUND）。
3. 编辑宿主 `koishi.yml`：注释掉 `group:console` 下的旧插件 `market-next:hgaird`，新增 `marketn-refactored:<随机id>: {}`（ns-require 自动补 `koishi-plugin-` 前缀，经 symlink 解析到本仓库）。
4. `yarn dev`：console devMode 自动开启（NODE_ENV=development），addEntry 的 dev 路径生效，client 由宿主 `/vite/@fs/...` 实时编译——此路径无需 dist。

### 2. dev 模式冒烟清单

全部逐项人工验证：

**市场页**：
- [ ] 索引加载（11 端点竞速、缓存复用、慢加载警告与跳设置入口）
- [ ] 搜索（token 化：is:/not:/impl:/locale:/category:/日期比较）、过滤（badge/category 计数）、排序（recommend/download/created/updated）
- [ ] 头像加载与降级（gravatar/cravatar/npm 候选链、失败缓存）
- [ ] 索引 debug 卡（对象数/解码大小/压缩比/候选端点/timings/路由评分）

**依赖页**：
- [ ] 分组折叠（持久化 collapsedGroups）、grid/list 布局切换、过滤下拉、搜索（Ctrl+K）
- [ ] 依赖卡片 11 态、版本选择（写 override）、忽略更新对话框（永久/限时）

**安装域**：
- [ ] 单包安装全流程：面板 → 进度日志终端（market/install-log 广播）→ 历史 → 详情（复制日志）
- [ ] bulkMode（只写 override，批量确认对话框应用）
- [ ] bundle 安装/卸载（成员选择/冲突告警/敏感字段/diff 四象；卸载三选一）
- [ ] 环境快照列表 → diff 预览 → 恢复（含本插件自身时提示）
- [ ] 本地 .tgz 上传（拖拽/分块进度/预览/commit）与本地绑定（prepare-local-binding）
- [ ] registry failover：断主源后备用源推荐徽章 + 一键重试

**命令行**（authority 4）：`plugin.install` / `plugin.uninstall` / `plugin.upgrade -s -f` / `plugin.clear-avatar-cache`。

**通道**：5 个 DataService 初值与刷新；5 个广播（patch/registry/registry-status/clear/install-log）；`market/index` 的 http-gzip transport 与 snapshot HTTP 路由（ETag/immutable）。

### 3. prod 模式复验

`yarn build` 后宿主 `yarn start`：console 走 `/@plugin-<key>/index.js` 静态产物。重点复验：市场页加载、单包安装、bundle 流程（vite8 prod vs 宿主 vite5 dev 漂移风险）。

### 4. 已知风险点

- `exports.development` 在宿主不生效（无 --conditions）——一切以 lib/ 构建为前提；
- prod 只探测 `dist/style.css`——构建后核对产物名；
- 旧插件 `market-next` 必须禁用，否则页面/服务冲突。
