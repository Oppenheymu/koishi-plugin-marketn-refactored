## 各阶段详情

### P0 基线 ✅

工具链全就位：tsdown（node/shared 双入口 → `lib/`）、vite 8（client → `dist/`，对齐官方打包）、vitest 4、biome（src）+ eslint+vue-parser（client）、`scripts/check-size.mjs` 行数预算与依赖方向门禁。`yarn install` 通过。

### P1 shared 平移 ✅

`src/shared/` 6 文件：types / provider / bundle / dependency-source / update / index。从旧 shared 原样平移，达标（最大 239 行）。

### P2 core 建设 ✅

8 模块 53 文件全部建成（详见 [core层模块参考.md](core层模块参考.md)）：

- **utils**（5 文件）：格式化/数值/防抖 JSON 落盘/异步/时间常量
- **racing**（4）：竞速三件套——合并旧 Installer 与 MarketProvider 两套重复实现（最大单点收益）
- **registry**（8）：RegistryClient 门面 + 缓存/重试/探测/归因/持久化
- **market**（11）：MarketIndexSource 门面 + 竞速拉取/磁盘缓存 v3/后台刷新/快照组装
- **deps**（2）：DependencyResolver 依赖快照与 latest 刷新
- **install**（12 + logs/3）：InstallOrchestrator 状态机 + 串行锁/runner/planner/回滚/日志三件套
- **upload**（4）：分块会话/tar 安全校验/本地绑定
- **environment**（3）：快照模型/diff/恢复规划

门禁验证：`tsc --noEmit` ✅、`biome check src` ✅（0 error）、`check-size` ✅（0 超限失败、0 处 core 层 koishi 违规；3 个 >300 警告属可解释范围）。

附带修复的旧 bug：agent 检测未 await（永远退回 npm）、execa v10 API 适配。
