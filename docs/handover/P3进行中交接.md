## 2. 关键架构决策（已定，别推翻）

1. **去 namespace**：erasableSyntaxOnly 禁止带运行时成员的 namespace，故 Installer.Config / MarketProvider.Config 改成顶层 InstallerConfig（interface + const 同名，type/value 两命名空间）与 MarketProviderConfig。config.ts 已引用新名。
2. **agent 注入**：门面 private readonly agent: PackageManagerAgent = { name: 'npm' }，构造后 void detect().then(r => { if(r){ this.agent.name=r.name; this.agent.version=r.version } })。orchestrator 持同一对象引用，install 时读到最新值。
3. **httpFactory**：ctx.http.extend({ endpoint, timeout })（返回 any），包一层 { get(path, cfg) } as RegistryHttpClient。
4. **market http**：MarketSourceDeps.http 类型是 (endpoint)=>{getText:never}（never 桩），适配层 cast as MarketSourceDeps['http']；getText 用 ctx.http.extend(...)(path,{responseType:'text',...}) 取 .status/.data/.headers。
5. **addEntry** 用 dirname(fileURLToPath(import.meta.url)) + resolve(here,'../../client/index.ts')（dev/src 与 prod/lib 均正确）。
6. **zod 契约**：listeners.ts 里 assertContract(name, ...args) → (contracts[name] as z.ZodType).parse(args)，listener 入口统一校验。

## 3. 剩余工作（按顺序）

### 3.1 修 tsc 错误（最重要）

上次 npx tsc --noEmit 的报错已分类，逐类修：

**(A) Dict 需 import type**（verbatimModuleSyntax）。涉及 bundle.ts / commands.ts / config.ts / data-store.ts / index.ts / installer.service.ts / providers.ts：把 import { Dict } 改成 import type { Dict }（Dict 仅作类型）。installer.service.ts 的 HTTP 也是 type，同样 import type。

**(B) key.split(':',1)[0] 返回 string|undefined**（noUncheckedIndexedAccess）。config-manage.ts / bundle.ts 里 const [prefix] = key.split(':',1) 改 key.split(':',1)[0]!。

**(C) commands.ts session 可能 undefined**：每个 action 开头加 if (!session) return;。另 { [installed]: null } 传 Dict<string> 报错——改 { [installed]: null as unknown as string } 或把 install 的 deps 参数放宽。options/session 多处加 !。

**(D) refresh('config'/'packages') 不在 Console.Services**：index.ts 的 declare module '@koishijs/console' { namespace Console { interface Services {...} } } 里补 config: unknown; packages: unknown;（这俩本由 @koishijs/plugin-config 全局增强提供，但未 import 不生效）。

**(E) erasableSyntaxOnly + 参数属性**：installer.service.ts constructor(public ctx: Context, ...) 的 public ctx 违规。改为显式字段：public ctx: Context; 字段声明 + constructor(ctx: Context, ...) { super(ctx,'installer'); this.ctx = ctx; ... }。base Service 已有 protected ctx，子类公开同名需 override 修饰（见 F 条）。

**(F) noImplicitOverride 的 override 缺失**：data-store.ts get()/patch()、providers.ts get()、installer.service.ts start()、market.service.ts get()/start() 都需加 override 修饰（它们 override DataService/Service/MarketProvider 基类成员）。

**(G) snapshot-transport.ts constructor(private ctx, private route)** 参数属性违规（erasableSyntaxOnly）。改显式字段 + 赋值。

**(H) exactOptionalPropertyTypes 的 undefined 赋值**：多处。典型：
  - config.ts removeConfig: Schema.union([Schema.const(undefined),...]) 默认 undefined 与 Schema<Config> 的 removeConfig?: boolean 冲突 → 接口 removeConfig?: boolean | undefined 或 Schema 去掉 Schema.const(undefined)。
  - normalizeMarketSilentRules 返回对象带 type/note/enabled: undefined → 用 ?? undefined 或条件展开。
  - data-store.ts migrateFromConfig 的 patch.updateIgnored = config.updateIgnored（undefined 赋值给非 undefined 字段）→ ?? {} 或改接口为 | undefined。
  - bundle.ts groupKey/label: string|undefined 赋给 BundleInstallResult.groupKey?: string 等 → ?? undefined。
  - installer.service.ts RegistryClientConfig / InstallOrchestratorConfig 的 timeout: config.timeout（undefined）→ config.timeout ?? undefined。
  - market.service.ts 同上 timeout。

**(I) registryFailurePenalty(options.reason)** 参数类型 string|undefined 传 RegistryReason|undefined：installer.service.ts 的 RouteStatsBook failurePenalty 里 options.reason 是 string|undefined，需 as RegistryReason | undefined（import type RegistryReason from core/registry/errors.js）。

**(J) avatar.ts noPropertyAccessFromIndexSignature**：record.key → record['key'] 等（normalizeAvatarDiskCache 里访问 Record<string,unknown> 的属性用方括号）。isPrivateAddress 里 const [a,b]=parts 的 a/b 可能 undefined → parts[0]! / parts[1]!。

**(K) listeners.ts**：lookupMarket 的 result.services[service] 可能 undefined → result.services[service]!.push(...)；ctx.console.services.market 类型是 shared 基类，传 node MarketProvider 需 cast；market/registry 里 entries.filter(Boolean) 后 Object.fromEntries 类型收窄 → .filter((e): e is readonly [string, PackageVersions] => !!e)；market/package 返回 Registry|undefined 但 Events 声明 Promise<Registry> → Events 里改成 Promise<Registry | undefined> 或 listener 里 !...。

**(L) 未使用变量（noUnusedLocals）**：bundle.ts installBundle 里 const start = Date.now() 没用到（删或补日志）；config-manage.ts 的 findPluginConfig / hasPluginConfigInGroup 重复定义但只 bundle.ts 用（删 config-manage.ts 里未用的那两份）。
