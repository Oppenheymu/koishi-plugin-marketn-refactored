## 3. 关键坑（P5 必读）

1. **`.vue` 文件不进 tsc 编译单元**——`import type {}` 写在 .vue 里对 `tsc -p client/tsconfig.json` 完全无效（本会话因此踩过：plugin-config 类型没生效、相对路径错误漏检）。**类型加载必须放 .ts 文件**（现放 `client/extensions/index.ts` 与 `src/node/index.ts`）；`.vue` 的 import 路径只有 vite build 才验证。改完 .vue 的 import 必须跑一次 `yarn build:client`。
2. **类型接线机制**（P5 若遇 store 属性缺失照此排查）：`store.X` 的类型 = `Console.Services[X] extends DataService<infer T> ? T : never`。Services 的声明合并来源：本插件 `lib/node/index.d.ts`（dependencies/registry/registryStatus/marketData）+ `src/shared/provider.ts` 编译产物（market）+ 宿主 `@koishijs/plugin-config`（packages/services/config）。**client 的 `import type ... from 'koishi-plugin-marketn-refactored'` 依赖 lib/ 已构建**——全量验证前先 `npx tsdown`。
3. **vue-compat.d.ts 必须是模块**（含 `export {}`）：放在全局脚本（如 env.d.ts）里的 `declare module 'vue'` 是环境模块声明，会整体遮蔽真实 vue 类型（本会话踩过，报 "Module 'vue' has no exported member 'ref'"）。
4. **typescript 锁 ~6.0.3**：升回 7.x 会让 @typescript-eslint/parser 在 require 时 throw（`yarn check` 第 4 步挂）。升级需等 typescript-eslint 支持 TS ≥7.1。
5. **vue 锁宿主 3.5.41**：其 `shallowReactive` 品牌类型靠 `client/vue-compat.d.ts` 垫片兼容；若宿主 vue 升级或 @koishijs/client 适配后可删。
